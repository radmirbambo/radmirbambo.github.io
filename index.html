AI-проекты

invite-bot

Telegram-агент: ищет информацию о человеке в сети и пишет ему персональное приглашение голосом основателя.

Работает в Бизнес-клубе МФТИ. Claude API, web search, Railway.

pitch-coach

AI-копилот для питчей: разбирает слабые места, переписывает историю и играет скептичного инвестора.

RAG по реальным питчдекам, дообученные эмбеддинги: Recall@1 на 10,7% выше базовых.

podkast-llm

Telegram-бот, который советует подкасты по каталогу Яндекс Музыки. Понимает голосовые.

RAG: эмбеддинги, чанкинг, векторный поиск.

Job Application Agent

Читает вакансию, сверяет с профилем навыков и пишет отклик под тип роли.

Agentic loop с детектором типа роли. Пользуюсь им для реальных откликов.
